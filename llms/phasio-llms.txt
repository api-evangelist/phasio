# Phasio

> Phasio is an operating platform for manufacturing service providers, unifying intelligent CAD-based quoting, production operations, connected back-office/ERP integration, part intelligence, and white-labeled customer storefronts. The Manufacturer API (v1) exposes orders, quotes, requisitions, part specifications, shipments, production steps, and webhooks over OAuth 2.0.

## API
- [Phasio Manufacturer API v1](https://docs.phas.io/developers): OpenAPI 3.1 REST API, base https://m-api.eu.phas.io/api/manufacturer/v1, OAuth 2.0 client-credentials Bearer JWT, 481 operations across 85 controllers.
